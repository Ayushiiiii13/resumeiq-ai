# ResumeIQ AI

An AI-powered Resume ATS Checker and Analyser built to help users improve their resumes for better job application success.

## Overview

ResumeIQ AI is a web application that analyses resumes using AI-based evaluation techniques and provides ATS (Applicant Tracking System) compatibility insights. The platform helps users understand how well their resumes align with modern hiring systems and improve their chances of getting shortlisted.

This project is designed with a clean frontend interface and a powerful backend that processes resume data, analyzes content, and generates useful feedback.

# Installation & Setup

## 1. Clone the Repository

```bash
git clone https://github.com/Ayushiiiii13/resumeiq-ai.git
```

## 2. Navigate into the Project Folder

```bash
cd resumeiq-ai
```

---

# Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file inside the backend folder and add:

```env
PORT=5000
EMAIL_USER=your_email
EMAIL_PASS=your_password
```

Start the backend server:

```bash
npm start
```

---

# Frontend Setup

Open a new terminal:

```bash
cd frontend
npm install
npm start
```

---

# How It Works

1. User uploads a resume.
2. The backend processes the uploaded file.
3. AI/ATS analysis is performed.
4. The system generates feedback and scoring.
5. Results are displayed on the frontend dashboard.
